# MCUXpresso SDK Manifests with Connectivity Addons

This repository contains West manifest files for installing the MCUXpresso SDK with connectivity modules, specifically designed for Matter development on NXP MCU platforms.

## Repository Contents
- `west.yml` : Complete West manifest file that pulls all MCUXpresso SDK components and connectivity modules.
- `west_matter_minimal.yml` : Minimal West manifest for Matter development that pulls only essential components for Matter projects.

## Getting Started

For comprehensive installation instructions and getting started guidance, please refer to the [Matter Documentation](https://docs.mcuxpresso.nxp.com/matter/latest/html/index.html) for NXP MCU platforms.
